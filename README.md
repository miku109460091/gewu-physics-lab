# 格物 · 高中物理实验室

一个面向高中生的分层物理学习网站：把**理论讲解、互动实验、例题精析**放在同一个学习空间里，并按照「筑基 / 进阶 / 挑战」三种层级重新组织内容。

站点为纯静态实现，无外部依赖、无需构建、无需登录，学习进度保存在本机浏览器 `localStorage`。

## 快速启动

**最简单的方式：直接双击 `index.html`。**

页面已经内置了打包后的 `js/bundle.js`，不依赖本地服务器，双击即可打开完整的学习空间。

如果希望获得最稳定的体验（尤其是学习进度持久化、CSV 下载等），建议双击 **`启动格物.bat`**，脚本会自动启动本地服务器并打开浏览器。

也可以手动启动：

```powershell
python server.py
```

然后访问终端中打印的地址（默认 `http://127.0.0.1:4173/`）。如果端口被占用，脚本会自动尝试下一个端口。

> 浏览器直接打开本地文件时，部分浏览器会限制 `localStorage` 的持久化。此时课程内容、实验和例题都可以正常使用，但学习进度可能无法在关闭页面后保留；需要长期保存进度时请使用 `启动格物.bat`。

## 在其他电脑打开

**方式一：离线复制（最简单）**

把整个 `physics-lab` 文件夹复制到另一台电脑（U 盘、网盘、压缩包均可），双击其中的 `index.html`。不要把 `index.html` 单独拷出来，CSS、JS 和数据文件需要和它放在同一目录结构中。

**方式二：同一局域网共享**

在运行网站的电脑上双击 `启动格物-局域网共享.bat`，或执行：

```powershell
python server.py --lan
```

终端会打印一个形如 `http://192.168.x.x:4173/` 的局域网地址。同一 Wi-Fi 下的其他电脑用浏览器访问这个地址即可。首次启动如果 Windows 防火墙弹窗，请允许 Python 访问专用网络。

**方式三：部署到公网**

`physics-lab` 是纯静态网站，可以把整个文件夹上传到 GitHub Pages、Netlify、Vercel、Cloudflare Pages 等静态托管平台，获得一个公网网址。

## 课程覆盖

- **运动与力**：匀变速直线运动、牛顿运动定律、动量与碰撞
- **曲线运动与能量**：平抛运动、圆周运动、机械能守恒
- **电场与电路**：电场强度与电势、闭合电路欧姆定律
- **磁场与电磁感应**：磁场与带电粒子、电磁感应与楞次定律
- **振动、波与光**：简谐运动、机械波、光的折射与全反射
- **热学与近代物理**：气体实验定律、光电效应、原子核与核能

每节课包含：

- 3–4 个核心概念与易错提示
- 4 条核心公式及其适用条件
- 2 个典型模型与可复用的解题流程
- 2 组常见误区对照
- 3 道分层例题（基础 / 进阶 / 挑战），每题都有分步解析、答案与思路提示
- 3 道即时自测题与解析

## 互动实验

1. **匀变速直线运动**：调节初速度、加速度，观察小车、v–t / x–t 图像与实时读数
2. **平抛运动**：调节初速度、抛射角、高度，显示轨迹、速度矢量与射程
3. **闭合电路欧姆定律**：调节电动势、外电阻、内阻，实时显示电路、I–V 关系与 P–R 曲线
4. **简谐运动**：调节质量、劲度系数、振幅，观察弹簧振子、x–t 图像与动能 / 势能转化
5. **一维碰撞与动量**：调节质量、初速度、恢复系数，验证动量守恒与能量损失
6. **凸透镜成像**：调节焦距、物距、物高，实时生成光路图并判断实像 / 虚像
7. **光电效应**：调节波长、逸出功、光强、电压，观察光电子发射、遏止电压与 I–V 曲线

每个实验都提供：

- 可操作的参数滑块与播放 / 暂停 / 重置
- 实时物理量读数
- 实验目的、原理和观察重点
- 实验任务清单（可勾选）
- 「记录当前数据」与实验记录表（最多 20 组）
- CSV 导出
- 配套知识点链接

## 分层设计

侧边栏的层级开关会持久化到本机：

- **筑基**：概念、单位、公式适用条件与基础模型
- **进阶**：典型模型、过程拆解、图像法与方程书写
- **挑战**：多过程、临界条件、跨模块综合与压轴题思路

每道例题和每节课程都按三阶组织，学生可以从任意一层开始，也可以切换层级重新查看推荐路径。

## 如何继续扩充内容

- **新增课程**：在 `js/data/lessons-*.js` 中按照已有结构添加对象，并在对应模块的课程数组中加入即可。课程编号、模块和例题 ID 必须唯一。
- **新增实验**：在 `js/sim/` 中新建模块，导出 `mountXxx(container, api)`，然后在 `js/simulations.js` 的映射表中注册，并在 `js/data/core.js` 的 `labs` 中添加元数据。
- **新增板块**：在 `js/data/core.js` 的 `modules` 中添加，注意 `id` 与课程中的 `module` 字段对应。
- **调整视觉**：颜色、间距、字号集中在 `css/style.css` 顶部的 `:root` 变量中。

修改源码后需要重新生成单文件入口：

```powershell
npx esbuild js/app.js --bundle --format=iife --target=es2020 --charset=utf8 --outfile=js/bundle.js
```

如果只是通过 `python server.py` 访问，也可以把 `index.html` 中的 `<script defer src="js/bundle.js"></script>` 临时改回 `<script type="module" src="js/app.js"></script>`，修改会立即生效。
